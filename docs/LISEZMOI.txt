FiveM GFX Manager
=================

AUCUNE INSTALLATION NECESSAIRE : double-clique sur FiveM-GFX-Manager.exe.
(Fonctionne sur Windows 10 et 11, qui ont deja tout ce qu'il faut.)
Garde le fichier .exe.config a cote du .exe.

Si Windows affiche "Windows a protege votre ordinateur" :
  clique sur "Informations complementaires" puis "Executer quand meme".
  (normal pour un logiciel sans signature payante)

UTILISATION CONSEILLEE
1. FiveM ferme et SANS mods -> onglet "Sauvegarde d'origine" -> "Creer la sauvegarde".
2. Onglet "Packs" -> choisis le type (Graphique, Son, Armes) -> "Ajouter des archives..."
   (ou glisse tes .zip / .7z / .rar / .rpf dans la liste). Les packs sont stockes dans la
   bibliotheque. Selectionne un pack -> "Installer". Plusieurs packs peuvent etre installes
   en meme temps (ex. un graphique + un son + des armes).
   "Ajouter des mods au pack..." ajoute d'autres fichiers a un pack de la bibliotheque.
   Onglet "Mods" : meme chose pour les mods seuls (routes, tracers, effets de
   feu...). Ajoute tes .rpf / archives, selectionne un mod -> "Installer" :
   ses .rpf vont dans FiveM.app\mods. Il s'installe a cote des packs.
3. Pour revenir en arriere : "Retirer de FiveM", ou "Restaurer FiveM d'origine".
   On peut selectionner plusieurs packs (Ctrl + clic) puis les retirer d'un coup ;
   clic droit sur un pack ou touche Suppr pour aller plus vite.
   En installant un nouveau pack son (ou autre) qui remplace les memes fichiers,
   le logiciel propose de retirer l'ancien automatiquement.
   Avant de coller un pack son, il cherche aussi dans tous les dossiers et
   sous-dossiers de FiveM.app (et dans GTA V\mods) les sons d'armes deja
   presents et propose de les mettre de cote (ils reviennent au retrait du pack).
4. Onglet "ReShade" -> "Installer ReShade" (telechargement automatique).
   En jeu, le menu ReShade s'ouvre avec la touche Debut (Home).
   Un pack peut etre installe par-dessus ReShade, inutile de le desinstaller avant :
   si le pack remplace le dxgi.dll de ReShade, celui de ReShade revient quand on retire le pack.
5. Onglet "QuantV" : pour mettre a jour QuantV. Le logiciel trouve QuantV dans tes packs ;
   donne-lui la nouvelle version (archive .zip/.7z/.rar, dossier ou .rpf, bouton ou glisser-
   deposer) et il remplace les fichiers QuantV du pack. Si le pack est installe, il est
   reinstalle tout seul. Tes reglages (.ini) sont gardes, l'ancienne version est sauvegardee
   dans %APPDATA%\FiveMGfxManager\quantv.
6. Onglet "Graphismes" (FiveM ferme) : Performance, Equilibre ou Qualite regle les options
   graphiques du jeu d'un clic. Tes reglages d'origine sont sauvegardes la premiere fois :
   "Remettre mes reglages d'origine" les remet.
7. Onglet "Presets ReShade" : choisis le preset actif (double-clic), duplique-le pour faire
   tes essais. "Mode performance" = plus de FPS (desactive-le pour modifier le preset en jeu).
   "Ranger les shaders inutilises" met de cote les shaders qu'aucun preset n'utilise :
   ReShade charge plus vite. "Remettre les shaders ranges" les remet.
8. Onglet "Profils" : installe tes packs, choisis preset et graphismes puis
   "Enregistrer la config actuelle". "Appliquer le profil" remet tout d'un clic
   (packs en trop retires, packs manquants installes, preset et graphismes remis).

Les sauvegardes sont dans %APPDATA%\FiveMGfxManager

REMARQUES
- Seuls les dossiers citizen, mods et plugins de FiveM.app sont geres.
  Packs son / armes : ils doivent etre fournis au format x64\... / update\... (ranges dans mods),
  ou en .rpf seul : le logiciel cherche le chemin de ce .rpf dans ton dossier GTA V
  (ex. POLICE_SCANNER.rpf -> mods\x64\audio\sfx\). Sans GTA V trouve, seuls les noms courants
  sont reconnus (RESIDENT.rpf, WEAPONS_PLAYER.rpf, EXPLOSIONS.rpf, update.rpf, x64?.rpf).
  Un .rpf dont le nom n'existe pas dans GTA V (ex. aQuantV.rpf) est pose a la racine de mods,
  comme on le fait a la main.
  Les sons du jeu (x64\audio\...) sont copies directement dans le dossier de GTA V
  (GTA V\x64\audio\sfx), comme le disent les tutos des packs son : FiveM ne les lit pas
  dans FiveM.app\mods. Les originaux sont sauvegardes et remis au retrait du pack.
  Ferme FiveM avant, et relance-le apres. Une verification des fichiers Steam ou une mise
  a jour de GTA V remet les sons d'origine : il suffit alors de retirer puis reinstaller le pack.
  Fichiers seuls (sans dossier citizen) ranges dans citizen\common\data :
    BloodFX (.ypt) -> effects   Kill effects (timecycle...xml) -> timecycle
    Roue des armes, position de la map (.gfx, frontend.xml...) -> ui
    No water (water.xml) -> levels\gta5
  Routes, tracers, effets de feu (.rpf) -> mods.
  Les fichiers bruts a remplacer avec OpenIV (.ytd, .ydr, .awc...) ne sont pas pris en charge.
- Les archives protegees par mot de passe ne sont pas prises en charge :
  decompresse-les toi-meme puis choisis "Dossier...".
- Certains serveurs interdisent ReShade ou les packs graphiques : verifie leurs regles.
